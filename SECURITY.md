# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report them privately, either through **[GitHub's private vulnerability reporting](https://github.com/tuntau-official/junction/security/advisories/new)** or by email to **[hello@tuntau.com](mailto:hello@tuntau.com)** with "SECURITY" in the subject.

Include what you can: the Junction version (Settings → About), your OS, steps to reproduce, and the impact you see. We'll acknowledge your report within a few working days and keep you posted until it's resolved. We're happy to credit you in the release notes if you'd like.

## Supported versions

Security fixes ship in the latest release, delivered through the in-app updater. Please make sure you're on the newest version before reporting.

## Scope

In scope: the Junction desktop app, its updater, the MCP server it exposes, and how it stores credentials and license data.
For the website, checkout or account dashboard at `tuntau.com`, use the same contact.
