## Inside the app

Junction has its own, much deeper reference built in — open **Learning** in the toolbar:

- **Tutorials** — guided, step-by-step walkthroughs on the example bookstore database.
- **Knowledge book** — a full SQL primer (from `SELECT` to window functions) plus a reference page for every node on the canvas.
- **`?` popovers** — most panels have a small `?` that opens the relevant knowledge-book page.

Can't find something? Press **⌘K / Ctrl+K** and type it — the command palette reaches every table, action and setting.
